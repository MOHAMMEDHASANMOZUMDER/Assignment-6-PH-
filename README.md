FITLOG — Workout Planning & Fitness Tracker

Description: Fitlog is a responsive modern web application that helps users explore workouts, add personalized plans and save plans. Also, users can remove them or mark them as done


Technologies Used:
Next.js, React.js, TypeScript, Tailwind CSS, DaisyUI
React Context API, REST API
LocalStorage
React Hot Toast
Lucide React


Features:

1. Browse workouts with their features.
2. Personalized workout plans.
3. Saving workout plans.
4. Localstorage for workout plans and saved workouts remain available after refreshing or reopening the page.
5. Workout statistics(duration, calories)
6. Data sorting according to duration, rating and calories
7. Responsive design.
8. Custom react hot toast notification.
9. Custom 404 page.
